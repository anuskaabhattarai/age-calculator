# age-calculator

## Project Description
A simple web application that takes the user's birth year as input and calculates their age using basic JavaScript.

## Features
* User input for birth year
* Calculates age instantly on button click
* Displays result dynamically on the webpage

## Technologies Used
* HTML
* JavaScript

## How to Use
* Enter your birth year in the input field
* Click on the "Calculate" button
* Your age will be displayed below

## What I Learned
* How to use variables in JavaScript
* Handling user input from HTML
* Performing basic calculations
* Updating content dynamically using DOM
